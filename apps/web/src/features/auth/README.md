# Auth (web)

Implementa acceso, recuperación y restablecimiento. `pages` compone rutas; `forms` contiene esquemas y vistas de formulario; `hooks` coordina navegación y estado; `services` consume `/auth`; `types` define el usuario y las entradas.

Se relaciona con `AuthProvider`, guards, navegación y todos los módulos protegidos. No almacena tokens en el navegador. Sprint propietario: 01.
