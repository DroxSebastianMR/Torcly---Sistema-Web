# Asistente IA

Burbuja de chat de solo lectura disponible dentro del Dashboard para usuarios con `assistant:read`. La web no contiene SDK ni configuración de Groq. Las fuentes que muestra cada respuesta enlazan únicamente módulos ya autorizados por el servidor.

La burbuja presenta el intercambio como mensajes de usuario y asistente. El módulo **Historial IA** permite releer únicamente las conversaciones guardadas por el usuario actual.
