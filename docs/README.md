# Documentación de Torcly

Este directorio separa las fuentes aprobadas, las decisiones vigentes, la arquitectura, los sprints y los controles de calidad. Los PDF y la hoja de costeo son fuentes de referencia; los Markdown son la guía operativa mantenida junto con el código.

## Mapa

- `00-fuentes/`: documentos originales del proyecto. No se editan desde el repositorio.
- `01-producto/`: análisis, flujos y hoja de ruta hacia el 30-35%.
- `02-arquitectura/`: arquitectura, frontend y estándar de módulos.
- `03-sprints/`: alcance, aceptación, pruebas y aprobación de cada sprint.
- `04-calidad/`: Definition of Done, medición, trazabilidad y estrategia Git.

## Fuente de verdad

En caso de contradicción se aplica este orden:

1. requerimientos y cambios formalmente aprobados;
2. reglas de negocio del SRS;
3. documentación del sprint aprobado;
4. arquitectura técnica vigente;
5. documentos históricos de estado.

Un estado declarado en un informe no reemplaza la evidencia del repositorio. Una historia solo se considera terminada cuando cumple la Definition of Done y el usuario aprueba el sprint.
