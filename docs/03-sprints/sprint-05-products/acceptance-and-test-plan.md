# Aceptación y pruebas - Sprint 05

- Código duplicado, precio negativo o campo obligatorio inválido se rechaza.
- Búsquedas combinables conservan resultados consistentes.
- Actualizar precio no reescribe datos transaccionales históricos.
- Desactivar excluye el producto de nuevas operaciones sin borrarlo.
- El campo de código acepta digitación y lector tipo teclado.
- El módulo no permite editar stock directamente.
- Test, typecheck, lint y build pasan.

Prueba manual: crear, buscar por tres criterios, editar, desactivar y confirmar que permanece consultable.
