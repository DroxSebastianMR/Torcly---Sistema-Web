# Sprint 42 - Grupos equivalentes de pago mixto

## Objetivo

Uniformar visualmente los dos bloques de un pago mixto en Caja, para que importe y método se presenten como partes equivalentes de una misma operación.

## Alcance

- Aplicar al primer importe y método el mismo contenedor que usa el segundo importe y método.
- No modificar montos, validaciones, métodos de pago ni registro contable.
