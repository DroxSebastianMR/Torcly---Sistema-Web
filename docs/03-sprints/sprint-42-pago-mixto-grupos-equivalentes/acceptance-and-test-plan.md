# Criterios de aceptación y pruebas

| Escenario          | Resultado esperado                                                                        |
| ------------------ | ----------------------------------------------------------------------------------------- |
| Pago con un método | Importe y método conservan el diseño actual.                                              |
| Pago mixto         | Primer y segundo importe/método se muestran en dos contenedores visualmente equivalentes. |
| Registro mixto     | El resumen y el comportamiento de registro no cambian.                                    |
