# Sprint 40 - Visibilidad de crédito en pago mixto

## Objetivo

Convertir la acción de dejar saldo a crédito en un botón secundario inequívoco dentro del diálogo de cobro inmediato.

## Alcance

- Usar el componente `Button` con la variante secundaria estándar y textos breves; cada acción conserva un ancho natural según su contenido.
- Mantener la jerarquía: crédito como acción secundaria y cobro final como acción principal.
