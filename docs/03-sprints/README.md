# Plan de sprints

Los sprints son secuenciales y cada uno tiene una rama, alcance cerrado, criterios de aceptación, plan de pruebas y acta de aprobación. El siguiente sprint no comienza hasta que el usuario pruebe por completo el incremento anterior.

| Sprint | Carpeta                        | Rama                                   |
| ------ | ------------------------------ | -------------------------------------- |
| 01     | `sprint-01-foundation-auth`    | `feature/sprint-01-foundation-auth`    |
| 02     | `sprint-02-users-access`       | `feature/sprint-02-users-access`       |
| 03     | `sprint-03-customers`          | `feature/sprint-03-customers`          |
| 04     | `sprint-04-vehicles`           | `feature/sprint-04-vehicles`           |
| 05     | `sprint-05-products`           | `feature/sprint-05-products`           |
| 06     | `sprint-06-inventory-services` | `feature/sprint-06-inventory-services` |

El porcentaje solo cambia después de completar [Definition of Done](../04-calidad/definition-of-done.md) y registrar la aprobación.
