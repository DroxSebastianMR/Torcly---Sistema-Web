# Matriz de pruebas

- Con cada consulta pendiente, las tarjetas KPI muestran bloques animados, no
  texto `...`.
- Las tablas de Cotizaciones, Preventivo y Suscripciones muestran seis filas
  con el mismo patrón de icono, dos líneas y acción.
- Con datos o lista vacía, el skeleton desaparece y no modifica el resultado.
