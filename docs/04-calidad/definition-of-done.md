# Definition of Done

Una historia solo puede marcarse como terminada cuando cumple todo lo aplicable:

- criterios de aceptación y reglas de negocio trazados;
- UI responsive y accesible en laptop y tablet;
- validación cliente y servidor;
- endpoint protegido por autenticación y permiso;
- persistencia real y migración reproducible;
- operación crítica transaccional y auditable cuando corresponda;
- estados de carga, vacío, éxito y error;
- pruebas unitarias, integración y flujo principal;
- `pnpm test`, `pnpm typecheck`, `pnpm lint` y `pnpm build` pasan;
- README del módulo y documentación del sprint actualizados;
- evidencia de prueba registrada;
- revisión completa y aprobación expresa del usuario.

No cuentan como terminado: mockups, placeholders, datos solo en memoria, endpoints sin UI, UI sin API, pruebas omitidas o documentación sin comportamiento ejecutable.
